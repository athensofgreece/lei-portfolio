# Security Policy

## Supported Versions

The latest deployed version of this portfolio is the only version currently supported with security updates.

## Reporting a Vulnerability

If you discover a potential security issue, please use GitHub's **Private vulnerability reporting** feature for this repository:

https://github.com/athensofgreece/lei-portfolio/security/advisories/new

Please avoid publicly posting details of a suspected vulnerability before it has been reviewed. Reports should include a brief description, steps to reproduce (if applicable), and any potential impact.

I will review reports and respond as soon as reasonably possible. This is a personal portfolio project, so response times may vary.
